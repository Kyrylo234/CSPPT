# 🧑‍🏫 Computer Science PowerPoint (CSPPT)

A **presentation tool for computer science students and developers**, designed to go beyond traditional slides by integrating **UML diagrams, a built-in command line, and live coding support** — all inside your slides.

## ✨ Unique Features
- **UML Diagram Support**
- **Integrated Command Line**
- **Live Coding During Presentations**
- **Standard Presentation Features:**
  - Text, images, graphs, videos, audio, shapes, and tables  
  - PDF exporting  
  - Animations and transitions  

## ⚙️ Build Instructions

```bash
unzip scc210-77.zip
cd scc210-77
mvn compile
mvn exec:java -Dexec.mainClass="org.lancaster.group77.Main" -Dexec.classpathScope=compile
```

### Shortcuts:
- CTRL+C to copy components or slides
- CTRL+X to cut components or slides
- CTRL+V to paste components or slides
- CTRL+M to open the command line (Can be used in slideshow)
- DELETE to delete components or slides
- CTRL+S to save the presentation to a CSPPT file
